# Hyderabad's Biryani — Mobile Web App

This is a standalone mobile-first web page based on the React Native/Expo app from the supplied ZIP.

## Run
1. Extract this folder.
2. Open `index.html` directly in Chrome/Edge, or use VS Code + Live Server.
3. For the best phone-style experience, open it on a phone or use browser device emulation.

## Features
- Vintage Hyderabad / Nizami visual style
- Mobile bottom navigation
- Home, Trail, Map and More sections
- Restaurant search and locality filters
- Near Me button using browser geolocation + Google Maps
- Restaurant locations and details
- Heritage story and gallery
- Ranking section
- Responsive desktop layout too
